# LegendaryOS
What is LegendaryOS? It's a Fedora-based Linux distribution designed primarily for users with NVIDIA graphics cards.

## Does LegendaryOS use a special kernel for gaming?
It does not use the default Fedora kernel, in the future there are plans for LegendaryOS to have its own special kernel.

## What's so special about LegendaryOS?
LegendaryOS offers a Plasma, Gnome, Cosmic, or Blue graphical environment (depending on the image). I also offer special CLI tools such as: lpm - a frontend for distrobox/toolbox, rpm-ostree, or bootc, legendary/legendaryos/legend - this is primarily a LegendaryOS CLI tool that offers many commands, such as comma for updating the entire system or disabling motd in the terminal. Additionally, LegendaryOS has a GUI application called the LegendaryOS App. It allows you to connect the Android ecosystem (your phone) with HackerOS (your VM or container), and of course, LegendaryOS.

## What graphical environments does LegendaryOS have?
LegendaryOS has 4 separate images with different graphical environments 1. KDE 2. Gnome 3. Cosmic 4. Blue

## How often are new LegendaryOS images released?
New LegendaryOS images are released every six months, more often if there are any bugs or problems.
