= 🇵🇱 Dokumentacja — język polski

== Czym jest LegendaryOS?

LegendaryOS to dystrybucja Linuxa oparta na Fedorze, zaprojektowana przede wszystkim z myślą o użytkownikach posiadających karty graficzne NVIDIA.

== Czy LegendaryOS używa specjalnego jądra dla graczy?

LegendaryOS korzysta z domyślnego jądra Fedory. W przyszłości planowane jest stworzenie własnego, dedykowanego jądra systemu.

== Co wyróżnia LegendaryOS?

LegendaryOS oferuje środowisko graficzne Plasma, GNOME, COSMIC lub Blue (w zależności od wybranego obrazu).

Dostępne są również specjalne narzędzia CLI:

`lpm`:: Frontend dla distrobox/toolbox, rpm-ostree lub bootc.
`legendary` / `legendaryos` / `legend`:: Główne narzędzie CLI systemu LegendaryOS, oferujące wiele komend — takich jak aktualizacja całego systemu czy wyłączenie motd w terminalu.

Ponadto LegendaryOS posiada aplikację graficzną *LegendaryOS App*, która umożliwia:

* integrację ekosystemu Android (telefon) z HackerOS (maszyna wirtualna lub kontener),
* pełną współpracę z systemem LegendaryOS.

== Dostępne środowiska graficzne

Nowe obrazy LegendaryOS są wydawane co sześć miesięcy. W przypadku wykrycia błędów lub problemów aktualizacje mogą być wydawane częściej.

= 🇬🇧 Documentation — English

== What is LegendaryOS?

LegendaryOS is a Linux distribution based on Fedora, designed primarily for users with NVIDIA graphics cards.

== Does LegendaryOS use a special kernel for gaming?

LegendaryOS does not use the default Fedora kernel. In the future, there are plans for LegendaryOS to ship its own dedicated kernel.

== What makes LegendaryOS special?

LegendaryOS offers a Plasma, GNOME, COSMIC, or Blue graphical environment (depending on the chosen image).

It also provides special CLI tools:

`lpm`:: A frontend for distrobox/toolbox, rpm-ostree, or bootc.
`legendary` / `legendaryos` / `legend`:: The primary LegendaryOS CLI tool, offering many commands — such as updating the entire system or disabling the motd in the terminal.

Additionally, LegendaryOS includes a GUI application called *LegendaryOS App*, which allows you to:

* connect the Android ecosystem (your phone) with HackerOS (your VM or container),
* seamlessly integrate everything with LegendaryOS.

== Available graphical environments

LegendaryOS provides 4 separate images with different graphical environments:

[cols="^1,^3", options="header", width="60%"]
|===
| #
| Graphical Environment

| 1
| COSMIC

| 2
| Blue
|===

== How often are new LegendaryOS images released?

New LegendaryOS images are released every six months. If any bugs or issues are discovered, updates may be released more frequently.
